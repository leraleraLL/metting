# Маленькие планы ♡

Нежный сайт-приглашение на прогулку или в кафе. Последовательные экраны помогают выбрать занятие, день и время, после чего можно скопировать готовый ответ.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются: стили, стикеры и JavaScript находятся внутри файла.

## Возможности

- Четыре последовательных экрана с переходами вперёд и назад.
- Выбор прогулки или кафе, даты и времени.
- Итог встречи и копирование ответа для отправки вручную.
- Адаптивная вёрстка для телефона и компьютера.

Ответы не отправляются автоматически и не сохраняются на сервере. Для доступа по публичной ссылке требуется отдельно настроить статический хостинг.
